# Pile Commander

#### Gestor de archivos de código abierto para personas creativas

Una aplicación de escritorio multiplataforma para Linux, Mac y Windows que almacena tus ideas en archivos bajo la ruta "Home / Documents / Pile Commander”.

https://github.com/user-attachments/assets/4449cc76-c38b-435d-ad81-007fd96474aa

# Cómo funciona la aplicación

El usuario crea widgets:
- individuales: texto, formas, conector, imagen, audio, video, modelo 3D;
- compuestos: contenedor, carpeta.

Toda la información sobre los widgets se almacena en archivos:
- texto y binario para la información del contenido;
- archivo yaml `.pile` para la meta-información.

Todos los archivos se almacenan en ```Documents/Pile Commander```, en el futuro será posible añadir almacenamientos en cualquier ruta.

https://github.com/user-attachments/assets/e6b5d3ad-7c04-4e51-8aa2-1c3bfc29fd06
