## Default Permission

Default permissions for the xattrs plugin

#### This default permission set includes the following:

- `allow-set-xattr`
- `allow-get-xattr`
- `allow-remove-xattr`
- `allow-list-xattrs`
- `allow-folder-with-children-xattrs`
